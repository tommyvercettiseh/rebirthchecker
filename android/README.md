# Rebirth Checker Android

Native Android-app met een echte verplaatsbare homescreen-widget.

## Eenmalig instellen

1. Open de app.
2. Kies de map die op dat moment speelt.
3. Vul de resterende minuten en seconden in.
4. Tik op **KALIBREER & START**.
5. Voeg daarna **Rebirth Checker** toe via de widgetkiezer van Android.

De kalibratie wordt gekoppeld aan een absolute systeemtijd. Daardoor blijft de rotatie doorlopen wanneer de app gesloten is, de telefoon opnieuw wordt gestart of je de widget later opnieuw toevoegt.

## Widget

De widget toont continu:
* huidige map
* live aftellende tijd
* volgende map

Rebirth Island wordt groen gemarkeerd.

De standaardrotatie is Rebirth Island, Fortune's Keep en Haven's Hollow, met 10 minuten per map.

Op recente Android-versies kan één keer toestemming voor exacte alarmen worden gevraagd. Daarmee kan de widget precies op het moment van een mapwissel verversen.
